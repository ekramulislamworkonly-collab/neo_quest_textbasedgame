# 🎮 Neo's Terminal Quest

An interactive text-based adventure game built entirely using **Bash Scripting**. Navigate through a mysterious world, make decisions, collect items, manage your health, and complete your mission—all from the Linux terminal.

---

## 📖 Overview

**Neo's Terminal Quest** is a command-line adventure game designed to demonstrate the capabilities of Bash scripting beyond traditional automation tasks. The game combines storytelling, user interaction, conditional logic, and random events to create an engaging terminal-based experience.

---

## ✨ Features

* Interactive menu-driven gameplay
* Health management system
* Inventory system
* Random events and encounters
* Loading screen animations
* Colored terminal output
* Multiple possible outcomes
* Pure Bash implementation
* Beginner-friendly code structure

---

## 🛠 Technologies Used

* Bash Shell
* Linux Terminal
* ANSI Escape Codes (for colored output)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/neo-terminal-quest.git
cd neo-terminal-quest
```

### Make the Script Executable

```bash
chmod +x neo_quest.sh
```

### Run the Game

```bash
./neo_quest.sh
```

---

## 🎮 Gameplay

You play as **Neo**, an explorer tasked with rescuing a missing scientist from an abandoned facility.

During your adventure you can:

* Explore dangerous areas
* Find useful items
* Discover hidden resources
* Fight against unexpected threats
* Make decisions that affect the outcome

Every playthrough can be different due to randomized events.
